# 🚀 Sobre el Proyecto

Este es mi **currículum digital**: una web estática, ligera y responsive donde presento mi formación, mis conocimientos y mis proyectos. Está construida desde cero con **HTML semántico, CSS y JavaScript puro**, sin frameworks ni librerías, y se publica gratis con **GitHub Pages**.

Soy estudiante de **2.º de Desarrollo de Aplicaciones Multiplataforma (DAM)** y este proyecto es mi carta de presentación para dar mis primeros pasos en el sector.

✨ **Características principales:**

- 🖤 **Diseño sobrio y moderno:** tema oscuro con detalles dorados, tipografía marcada y esquinas rectas.
- 🧭 **Menú lateral fijo:** con resaltado automático de la sección que estás viendo.
- 📱 **100% responsive:** en móvil el menú se convierte en un panel desplegable.
- 📄 **CV descargable:** botón para bajar mi currículum en PDF.
- ⚡ **Carga ultrarrápida:** sin dependencias, solo HTML, CSS y JS.

# 🧠 Contexto del Proyecto

Proyecto **personal** creado para reunir en un único sitio mi trayectoria académica, mis habilidades y mis trabajos, y practicar maquetación web, diseño responsive y organización del código.

# 🚀 Cómo Utilizar el Proyecto

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/ivanmarquez19/Curriculum.git
   ```
2. **Entra en la carpeta:**
   ```bash
   cd Curriculum
   ```
3. **Abre `index.html`** en tu navegador (en Linux: `xdg-open index.html`).

### Publicarlo con GitHub Pages

1. En el repositorio, ve a **Settings → Pages**.
2. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`, y pulsa **Save**.
3. En un par de minutos estará en `https://ivanmarquez19.github.io/Curriculum/`.
